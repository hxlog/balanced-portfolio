## 二、新发现：**同一指数、三家 PE 完全不同**（必须做产品决策）

以「中证中药 930641 / 2026-11-11~13」为例：

| 来源 | 口径 | 数值 |
|---|---|---|
| 平安证券 | `peRatio`（页面标 PE-TTM，分位按近 5 年） | **23.27** |
| ETF.run | 「指数的等权市盈数据」 | **29.75**（当前分位 29.79%，5 年分位） |
| 中证官网 | 市盈率1 / 市盈率2 | **19.55 / 19.67** |
| 乐咕 | 滚动PE / 滚动PE中位数（月频） | 需补测 |

说明：**加权 vs 等权、整体法 vs 中位数、静态 vs 滚动、除数是否剔除亏损股**，四类选择组合出的 PE 可以差 30% 以上，
分位数因此**不可跨源比较**。这不是数据质量问题，是口径问题——必须选定一套作为产品主口径，并在 UI 上标注。

## 三、对 D1（多源聚合）的直接影响

1. **日频 PE/PB/股息率历史**：只有平安能一次性给 5 年周频；中证官网只滚动 20 个交易日（可日积月累）；乐咕是**月频**。
   → 若放弃平安，上线首日「5 年分位」只能来自月频插值，精度与 etf.run 不一致。
2. **十年国债**：akshare `bond_zh_us_rate` 已可覆盖 2015 至今，**风险溢价可完全自建**，不必依赖平安。
3. **申万行业估值**：只有当前快照，无历史 → 「行业权重/行业估值」模块只能做当期，历史需自建滚动。
4. **东财快照类接口**在本机不稳定（可能 IP 限流），但**生产 ingest 每日正常**，判定为「可用但需重试 + 降级」。
