# 全站改版 · 原型内容规格（2026-11-27）

> 供三个视觉变体共用：内容、信息架构、交互必须一致，只允许视觉语言不同。
> 参考：用户已选原型风格 = `docs/prototypes/app/index2.html` 中的 **d1 / stockA / basketA / cryptoB**（sky 主色、13-14px 紧凑排版、白色圆角卡片、左栏、分段控件、迷你面板）；
> 交互/动效/loading 参考 **https://prologue.dev** 与 **https://prologue.dev/ui**（三级圆角 control/card/panel、柔光渐变品牌、glass header、spotlight hover、pill nav、reveal-rise 动效、mono 数字、Skeleton shimmer）。

## 0. 全局规则
- 语义色：**红涨绿跌（A股）**；上涨 #dc2626，下跌 #16a34a（暗色 #f87171/#4ade80）；主色 sky #0284c7（暗 #38bdf8），辅助品牌渐变 lavender→sky 仅用于强调/光晕，不大面积使用。
- 数字：全部 `font-variant-numeric: tabular-nums`，关键数字可用 Geist Mono。
- 布局：顶部 56-64px sticky glass header + 可选左侧 212px rail；内容容器 max 1480px，桌面 12 列栅格，区块间距 16-20px。
- **禁止全局 loading**：每个卡片/图表/表格用与自身尺寸一致的局部 Skeleton；数据到达各自淡入（reveal-rise），不阻塞整页。
- 动效：150-250ms，`cubic-bezier(.16,1,.3,1)`（expo-out），仅 opacity/translateY/scale；尊重 prefers-reduced-motion。
- 所有图表为内联 SVG（不依赖 CDN/网络），支持 hover tooltip（纯 JS 实现即可）。
- 响应式：≥1200px 桌面；768-1199 平板收左栏为顶部 tabs；<768 单列、按钮全宽。
- 暗色模式：follow system + 手动切换（右上角 icon），两套变量。
- 可访问性：对比度、focus ring、键盘可达、title/aria-label。

## 1. 页面 A：/valuation 指数估值首页
区块顺序：
1. **页头**：标题「指数估值」；右侧数据状态徽标 —— **全局行情数据更新至 2026-11-27**（绿色 dot），hover 展开明细面板：A股 11-27 / 港股 11-27 / ETF 11-27 / 基金净值 11-26 / 股指期货 11-27 / 指数行情 11-27 / 指数估值 11-27 / MVI 11-27；若未全部完成显示琥珀色「数据更新至 2026-11-26，2 项待更新」。
2. **Valuation Band 卡（核心）**：
   - 指数选择器 segmented：沪深300 / 中证A500 / 上证50 / 中证全指（默认沪深300）；旁边「近5年/近10年/全部」窗口切换。
   - 指标 tabs：PE-TTM / PB / 股息率 / 风险溢价（ERP）。**切换时不出现整页/整卡 loading**，仅数值与图表曲线 150ms 交叉淡入；切换 tab 不再重新请求指数列表。
   - 主图：估值分位带（当前值大数字 + 分位百分比 + 低估/中性/高估 badge），下方带状分位区间（机会值/中位数/危险值），x 轴近5年。
   - 右侧：4 个指标的 mini sparkline + 当前分位（点击可切 tab）。
   - 数据点 2026-11-27：沪深300 PE 13.4（5y 分位 42%）、PB 1.38（38%）、股息率 3.2%（61%）、ERP 5.1%（55%）。
3. **市场估值指数 MVI 卡**：
   - 标题 MVI + 两个 info 按钮：`估值分 ?`、`风险分 ?`（hover/click 显示：公式、因子、窗口、权重、in-sample 声明）。
   - 当前值 31.29，zone「低估」，估值分 68.71、风险分 66.92，因子贡献条（PE/PB/股息率/ERP/ROE）。
   - 近5年走势（去掉“0便宜/100贵”文字），折线 + 分位带，**平滑无跳变**（占位数据即真实修数后的周频序列，勿出现尖刺）。
   - **展开按钮「打开图表」**：modal 大图：左轴 MVI（0-100，渐变面积），右轴指数收盘价（默认中证全指 000985）；顶部指数切换（沪深300/A500/上证50/中证全指）；两张系列不同颜色 + 图例；响应式自适应宽度；hover 十字线显示日期、MVI、指数点位与分位。
4. **行业估值热力卡**：
   - 16 个行业方格（2 行），按 PE 分位着色（绿→黄→红，注意语义：低估偏绿/高估偏红），每个格显示行业名 + 分位 + 样本数。
   - 标题右侧 `?` tooltip：「行业估值热力 = 该行业下所有指数的 PE-TTM 近5年分位均值；样本数 = 参与计算的指数数量；分位越低越便宜」。
5. **红利指数吸引力卡**：
   - 右上模式切换 button：`绝对估值` / `相对估值`（默认绝对估值）。
   - 绝对模式：散点，x=PB（**对数轴**），y=股息率，气泡=基金规模，回归线 + R²；30 个红利/股息相关指数；hover 显示名称/代码/PB/股息率/规模。
   - 相对模式：x=PB 近5年分位，y=股息率近5年分位，四象限背景（左上=高股息低估值等），气泡=规模；说明文字一行。
6. **快速变化 / 指数列表**（简化表格）：指数名/代码、PE 分位、PB 分位、股息率分位、近1年收益；点击行进入详情页；表头排序；每行股票涨跌用红/绿。
