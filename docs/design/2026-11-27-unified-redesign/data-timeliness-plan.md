## 4. 免费源最大化聚合方案（按优先级）
1. **指数行情恢复（P0，最高优先级）**：新建 `scripts/index_quotes_free.py`：遍历跟踪指数，按「腾讯 ifzq → 新浪 → 中证官网 csindex → 东财」多源竞速/降级；每 15min 轮询；写 `bp_index_quote_daily`（source 记录实际来源）；对账日志。替代已停 index_quotes/csindex/xueqiu 三条旧 cron（不含个股/ETF 抓取）。
2. **清洗解耦（P0）**：legacy 清洗钩子不再以 coverage≥0.90 为触发条件（已改为 fetched>0 即跑 + 4h 节流）；增加「清洗对账」任务：每次指数行情完成后对受影响 symbol 增量重建 clean，并刷新 asset status；彻底解决 clean 停 11-26。
3. **backlog 清理（P0）**：旧 universe 产生的 9,434/9,496 条 backlog 属于历史口径错误，一次性删除/对账清理；run_backlog 只重放当前 universe 的 trade_date。
4. **估值/MVI 调度归位（已做，P0 验收）**：valuation cron + MVI 23:50；补 `bp_data_freshness` 状态写入；market valuation 与 10Y 换源。
5. **市场估值替代源（P0/P1）**：东财 clist 封禁 → 用 akshare 的交易所/中证估值文件或自行用指数估值聚合出板块近似（需口径评审）；短期 UI 隐藏对应卡片（Q15 答复：修不好先隐藏）。
6. **10Y 国债**：chinabond 公开接口 + akshare `bond_zh_us_rate` 兜底；失败保留上一交易日值与陈旧标记。
7. **快照缓存/失效（P1）**：CFFEX/估值/行情 API 缓存 TTL 1800s → 180-300s，落库后主动 invalidate；前端显示 as_of，避免「看起来是旧数据」。
8. **CFFEX 更早可见（P1）**：15:10-16:48 用期货日线/实时快照提供 provisional close，16:48 官方回填 settle；UI 标注 provisional。
9. **多源竞速/并发（P1）**：同一数据两源并行取，先到先写、后到校验覆盖；限速按源独立；免费源配额监控。
10. **可观测（P1/P2）**：统一 data freshness 表 + `/admin/market-data` 扩展 8 类数据 SLA 看板 + 失败告警（邮件/Webhook）；每天 09:30 生成昨日「全站数据体检报告」。
11. **免费源扩展（P2）**：中证/巨潮/交易所公开文件、乐咕、雪球备用、investing/stooq 海外兜底；**不采购、不搭代理池**（按用户 Q15 答复）。
