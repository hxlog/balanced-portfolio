## Next.js 性能审计结论（07-nextjs-performance.md）
Top 5（按收益排序）：
1. 删除根 layout 的 Suspense fallback={null}（会让全站失去静态 shell / PPR 失效）
2. ECharts 按需注册 + 懒加载（4 个图表路由各减 ~330KB gzip）
3. qrcode 改动态 import（每路由减 ~18KB gzip）
4. 移除 motion + 整页 AnimatePresence（dashboard 减 ~55KB gzip，INP 改善）
5. Dashboard 用 initialData 初始化 + /crypto 拆局部 Suspense、瘦身 RSC payload

新增页面强制 5 条规范：Server-first / 缓存显式化 / 局部 Suspense / RSC payload ≤100KB / 首屏 ≤2 图。
