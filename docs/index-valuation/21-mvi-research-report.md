# 21 · 市场估值指数 MVI 研究报告（v1）

> 脚本：`scripts/research_mvi.py`，原始结果：`mvi-research.json`（每日/每周可重跑）。
> 数据：5 大宽基（上证50 / 沪深300 / 中证A500 / 中证500 / 中证1000）周频估值序列，2022-05 → 2026-11，共 237 个周观测。

## 1. 因子化

| 因子 | 定义 | 方向 |
|---|---|---|
| PE 分位（反向） | PE_TTM 的 2 年滚动分位（min 26 周）取反 | 越高越便宜 |
| PB 分位（反向） | PB 的滚动分位取反 | 越高越便宜 |
| 股息率分位 | 股息率滚动分位 | 越高越便宜 |
| 风险溢价分位 | ERP 滚动分位 | 越高越便宜 |
| ROE 分位 | ROE = PB/PE×100（TTM 同源推导）的滚动分位 | 越高越高质量 |

- 5 个宽基的因子分位等权平均（缺数据的宽基跳过）→ 代表「全市场」。
- 标签：沪深300 未来 252 个交易日收益（bfq 收盘）。
- 因变量与因子均为百分位（0–100），无单位，权重可解释。

## 2. 三种模型与 walk-forward 结果

| 模型 | 方法 | 折1 IC（2023-11→2024-11） | 折2 IC（2024-11→2025-11） |
|---|---|---|---|
| A · 约束线性 + Spearman IC 最大化（SLSQP，w≥0，Σw=1） | 可解释权重 | **0.524** | **0.839** |
| B · PCA(2) + 岭回归（λ=100） | 共线性处理 | 0.378 | 0.850 |
| C · 梯度提升（depth-2 boosting，30 轮） | 非线性对比 | 0.078 | 0.523 |

**结论：A 与 B 显著优于 C；A 的权重在折1/折2 完全一致且可解释，B 的权重随折变化（PB 权重 0.40→0.49，ROE 被压到 0），稳健性不如 A。**

## 4. 重要方法学警示（必须写进页面说明）

1. **重叠窗口会抬高 IC**：未来 1 年收益在相邻周高度重叠，Spearman 自相关很大；0.84 的 IC 不能按独立样本解读。下一步应补充：
   - 非重叠采样（每 52 周取一个点）或 Newey-West 调整；
   - 分位组（十分位）未来收益单调性检验；
   - 趋势/波动率控制变量。
2. **样本量小**：237 周、仅 2 个 walk-forward 折；结论属于「初步可用」，需随数据积累滚动复核。
3. **ROE 为 PB/PE 推导**（TTM 同源），与真实 ROE 可能有口径差；未来可接入真实 ROE 历史。
4. **中证A500 2024-09 才发布**，早期日期只由其余 4 个宽基合成。

## 5. 建议的最终方案（待你确认）

- 模型：**A（约束线性 + IC 最大化）**，每日用最新周频数据重算权重与分数；
- 输出：MVI 0-100（0=极度低估，100=极度高估）+ 估值分；风险分用「波动率分位 + 最大回撤分位」合成（第二仪表盘，下一轮实现）；
- 页面：双仪表盘 + 5 因子贡献条 + 近 5 年 MVI 走势 + 「分区 → 未来 1 年收益统计」表（分位组样本数/平均收益/胜率）；
- 每日 17:00 任务刷新 + 缓存失效；研究脚本保留可复现。
