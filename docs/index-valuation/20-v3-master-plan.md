## 2. /valuation 交互重构（需求 1）

### 2.1 问题与方案
- 现状：`<Suspense key={window+metric} fallback=整页骨架>` → 每次筛选整块卸载重建 = 你看到的“整页闪”。
- 方案：**保留 URL + server component + PPR**，但把 Suspense 边界下沉到区块级：
  1. 外层 shell（标题、工具栏、筛选条）常驻不卸载；
  2. 每个数据区块独立 Suspense，key 不变 → 筛选时旧内容**保持可见**（降低透明度），顶部出现 2px 进度条；
  3. 区块数据用 `"use cache" + cacheTag("valuation")` 按 (window, metric) 缓存，切换命中缓存瞬间完成；
  4. 交互在 `startTransition` 中 `router.replace(..., {scroll:false})`，配合 React 19 View Transitions 做图表淡入/数字滚动；
  5. 服务端预热 5 窗口 × 4 指标（页面 mount 后后台 prefetch），实际点击基本零等待。
- 指标筛选移到 Valuation Band 卡片右上角（PE/PB/股息率/风险溢价），窗口筛选留在页头。

### 2.2 验收
- 点击筛选：无白屏、无整页跳动；旧图表半透明保留 → 新数据 300ms 内交叉淡入；
- 顶部细进度条 + 图表骨架只出现在目标卡片内；
- 首屏 LCP < 1s，切换 P95 < 400ms。

## 4. 市场估值指数 MVI（需求 3，重点研究）

### 4.1 数据与因子化
- 标的：5 大宽基（上证50/沪深300/中证A500/中证500/中证1000），周频估值序列 2021-11 起（262 点）。
- 原始因子：PE 分位、PB 分位、股息率分位、ERP 分位、ROE 水平（均为滚动 5 年分位，0-100）。
- 标签：未来 252 个交易日（1 年）的沪深300收益率（也可用等权宽基组合）。
- 因子方向约束：PE/PB 分位越低越便宜（负向），股息率/ERP/ROE 越高越好（正向）。

### 4.2 模型 / 损失函数（低维多因子共线性处理）
- 方法 A（推荐）：**约束线性加权 + Spearman IC 最大化**：`MVI_t = Σ w_i · z(f_i,t)`，s.t. w_i ≥ 0（方向约束）、Σw=1、L2 正则；损失 `L = -SpearmanIC(MVI_t, fwd_ret_t) + λ||w||²`；用 scipy 优化。
- 方法 B：主成分（PCA）+ 岭回归（消除共线性），输出各主成分贡献。
- 方法 C：梯度提升树（黑盒，仅作为 benchmark 对比，不用于最终信号）。
- 验证：walk-forward（2021-11→2024-11 训练，2024-11→2026-11 测试），报告 IC、分位组单调性、顶部/底部十分位组合的 1 年收益差、命中率、最大回撤；样本量有限（约 208 周）会如实标注。
- 输出：MVI 0-100（越高越贵/越危险，或反向 0=极度低估），分区标签（极度低估/低估/合理/高估/极度高估）。

### 4.3 每日刷新
- 每日 17:00 计算任务：取最新估值周频数据 → 计算因子分位 → 打分 → 落 `bp_market_valuation_index`（date, score, zone, factor_json, fwd_ret_stats）→ 刷新 Next 缓存 tag。
- 研究脚本 `scripts/research_mvi.py` 输出研究报告（权重、IC、分组回测）。

### 4.4 UI（类 Fear & Greed Dashboard）
- 顶部：大号仪表盘（0-100 分区配色）+ 当前分区 + 最近 5 年走势 sparkline；
- 中部：5 个因子条（当前值/历史分位/贡献权重），显示“便宜/贵”方向；
- 下部：MVI 与沪深300 走势双轴图 + 未来 1 年收益散点（按分区着色）+ 分区统计表（样本数/平均未来收益/胜率）；
- 底部：方法说明（可折叠）+ 更新时间。
- 验收：打开即见仪表盘与分区；历史回测气泡可 hover；移动端纵向堆叠。
