## 1. 产品定位

**一句话**：给做资产配置的人一个**看得懂、查得清、能编程**的指数估值工作台，并把「估值判断」直接接到「组合回测」上。

差异点（相对 etf.run）：
1. **口径可追溯**：每个指标带 `calc_src` 与 `basis`，多源并存、差异告警，不是黑盒数字。
2. **与组合打通**：估值页看到低估指数 → 一键加入篮子/组合 → 直接回测。
3. **可编程**：同一套数据通过受控 API 给 Excel / Python 使用，复刻分析师工作流。
4. **合约微观**：同一产品内提供 Binance 合约的持仓/多空/资金费率分位，用于跨资产风险判断。

非目标（明确不做）：交易执行与下单、社区/跟单、付费订阅、网格策略、AI 选股。

## 2. 目标用户与核心场景

| 角色 | 描述 | 核心诉求 | 关键页面 |
|---|---|---|---|
| **配置型投资者（主）** | 你自己：做风险平价/资产配置，季度调仓 | 当前哪些资产便宜？分位多少？和历史比如何？ | /valuation、/valuation/[code] |
| **研究者/分享对象** | 学习者、朋友、开源使用者 | 公开页面能看懂、数据有出处 | /valuation、/docs/api |
| **量化/分析师（API）** | 用 Excel/Python 拉数 | 批量、可复现、字段稳定 | /docs/api、/admin/api-tokens |
| **合约观察者** | 看加密市场情绪与拥挤度 | 多空比、OI、资金费率的分位 | /crypto |

### 2.1 三条主用户故事

1. 「我想知道现在沪深300 贵不贵」→ 首页看到 PE 20.47、分位 15.77% → 点进详情看 5 年/10 年分位与区间统计 → 判断低估。
2. 「我觉得中证500 便宜，想配一点」→ 详情页点「加入回测」→ 自动带出资产 → 选择篮子模式 → 跑风险平价回测。
3. 「我要在 Excel 里做月度估值表」→ 申请 token → 复制 Power Query 模板 → 一键刷新出 521 行估值快照。

## 5. 页面规格

### 5.1 `/valuation` 估值首页（P0）

| 区块 | 内容 | 交互 | 状态 |
|---|---|---|---|
| 页头 | 标题 + 「521 只指数 · 每日 21:00 更新 · 截至 YYYY-MM-DD」+ 排序/导出按钮 | 导出当前筛选 CSV | 加载：骨架屏 |
| 全市场估值 | 4 张卡（全市场/主板/创业板/科创板）：PE、PE 分位、PB、PB 分位 | 点击卡片 → 过滤到对应板块 | 无数据：显示「历史归档积累中（已 N 天）」 |
| 宽基指数 | 8 行表：收盘/涨跌/52 周/距最高/PE/PE 分位/PB/PB 分位/股息率/风险溢价 | 点行 → 详情；分位列颜色分级 | — |
| 全部指数 | 521 行表 + 筛选（类别/有 ETF/仅有估值）+ 排序 | 分页或虚拟滚动；搜索框 | 空态：无匹配 |

**筛选默认值**：全部类别、按 PE 分位升序以外的「默认排序 = 指数代码」；记忆上次筛选（localStorage）。

### 5.2 `/valuation/[code]` 指数详情（P0-P1）

| 区块 | 内容 |
|---|---|
| 页头 | 名称 + 代码 + 类型 + 徽标（低估/中性/高估）；右侧最新点位与涨跌 |
| Tab 1 指数指标 | 左侧「估值与点位」双轴大图（PE 左轴 / 点位右轴，窗口 5y/10y/上市以来）；右侧 PE 分位条 + 核心指标表（PB/股息率/风险溢价/ROE 及分位、均值）+ 成分股前 8 权重 + 极限跌幅水位 |
| Tab 2 成分与业绩 | 成分股权重表（前 N）+ 一级行业权重 + 业绩增长中位数（营收/净利同比，季度）+ 年度财务表 |
| Tab 3 ETF 资金 | 合计规模 / 净申购 / 折溢价 4 卡 + 净申购跟踪图 + ETF 申购明细表 |
|
**响应式**：≥1100px 用 D1（左图右栏）；<1100px 单栏；「专业模式」切 D3 三栏（仅 ≥1280px）。

**空/错态**：
- 无估值数据（如新指数）：Tab1 显示「暂无估值数据」+ 最后成功日期；
- 分位样本不足：显示「样本不足（N < 120）」，不显示百分比；
- 多源差异 > 20%：字段旁显示 ⓘ 角标，hover 显示「主口径 23.27 / 校验口径 19.55，差异 19%」（不显示来源名称）。

### 5.3 `/crypto`（P5 改造，新增模块置于现有看板上方）

| 顺序 | 模块 | 说明 |
|---|---|---|
| 1（新增） | 合约总览 | 4 KPI（全市场 OI、多空账户比、主动买卖比、BTC 资金费率）+ 合约表（Top N）+ 资金费率热力 |
| 2（新增） | 合约详情入口 | 点合约 → `/crypto/futures/[symbol]` |

**约束**：现有模块不动，新模块插入到页头之下；现有 `cacheTag("crypto")` 与新 `crypto-futures` 分 tag 失效，避免互相打穿。

### 5.4 `/crypto/futures/[symbol]` 合约详情（P5）

左列表（可搜索）+ 价格与 OI 双轴图 + 多空比/大户持仓比分位 + 资金费率表 + 5 指标 × 5 窗口分位统计表。

### 5.5 `/builder` 篮子模式（P4）

- 顶部：模式切换（四象限 / 一篮子）；一篮子下 6 种方法 + 再平衡阈值 + 集中度上限（单资产/分组）+ 回看窗口 + 最小历史。
- 资产表：资产 / 类别 / 目标权重 / 风险贡献 / 边际风险 / 调整滑杆。
- 风险预算：默认按分组（股票/债券/商品/海外），高级展开到单资产。
- 校验：权重合计 100%、单资产上限、分组上限；不满足时禁用「开始回测」。

### 5.6 `/admin/assets`（P3 改造）

资产新增/编辑支持 `category=stock`，复权选项开放给股票；列表徽章按类别泛化；批量设置默认口径。

### 5.7 `/docs/api` 接入中心（P2）

认证说明、端点表、响应结构、Power Query 模板、VBA 模板下载、Python SDK 示例、限频与错误码。**不需要登录即可阅读**；所有实际调用需要 token（Q30-A）。

### 5.8 `/admin/api-tokens`（P2，超管）

签发（名称/范围/过期）、列表（最后使用时间/调用量）、撤销。Token 明文仅创建时展示一次。

## 6. 关键交互流程

### 6.1 估值 → 组合
```
首页 → 详情 → 点「加入回测」→ 抽屉选目标组合（或新建）→ 自动带 category/quadrant=basket →
构建器额度校验 → 跑回测 → 跳 /dashboard 看结果
```

### 6.2 API 接入
```
/docs/api 复制示例 → /admin/api-tokens 签发（选 scopes）→ 明文只显示一次 →
Excel: 粘贴 Power Query / 加载 xlsm；Python: pip install bpdata（或直接下载单文件）→ 调通后看用量
```

### 6.3 股票三复权
```
添加资产搜索 600036 → 同时入库 bfq/qfq/hfq 三条序列 → 组合内默认 hfq →
切换口径触发局部重算（只影响该资产）→ 详情显示三口径差异表
```

### 6.4 加密监控
```
/crypto 顶部看 4 KPI → 发现多空比 30d 分位 86% → 点 SOLUSDT → 看大户持仓比与资金费率 →
判断拥挤度（仅观察，不构成策略）
```

## 7. 状态与文案规范

| 状态 | 规范 |
|---|---|
| 加载 | 骨架屏（不用转圈）；表格首屏 8 行骨架 |
| 空态 | 说明「为什么空」+ 下一步动作（如「历史归档积累中，已 12 天」） |
| 错误 | toast（sonner）+ 可重试按钮；不弹 alert |
| 危险 | AlertDialog 二次确认（删除 token / 重算全部组合） |
| 数字 | 千分位、2 位小数（百分比 2 位、PE/PB 2 位、点位 2 位）；缺失显示 `-` 不显示 0 |
| 颜色 | 涨跌按用户偏好（默认绿涨红跌）；估值分级：低估=success、中性=warning、高估=destructive |

## 8. 术语表（口径相关，必须在 /docs/api 与详情页 tooltip 一致）

| 术语 | 定义 |
|---|---|
| PE(TTM) | 滚动 12 个月市盈率；等权或加权取决于 `pe_basis` |
| 分位 | 当前值在窗口内历史分布中的位置，公式见 05 文档 3.5 |
| 风险溢价 ERP | 股息率(TTM) − 十年期国债到期收益率（同日） |
| 后复权 | 以最早价格为基准调整，含分红再投，回测默认 |
| PiT | Point-in-Time：以 `captured_at` 保证不用未来数据 |
| 极限跌幅水位 | 从历史最高点下跌 70%/80% 对应的点位 |
