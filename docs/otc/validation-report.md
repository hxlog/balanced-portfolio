## 3. 发现与修复

1. **双时钟缺口（已修复）**：原实现用单一日计数同时贴现与计票息；金标为 BUS252 贴现 + ACT365 票息。已新增 `discount_day_count` / `coupon_day_count`（默认沿用 day_count，向后兼容），金标用例已跑通。
2. **气囊解析公式错误（已修复）**：原公式为 `call_parti×CDO + reset_call_parti×CDI − knockin_parti×PDI`，与金标复制式 `KI参与率×(DIC−DIP) + 参与率×DOC` 不符（35% 波动率下低估 3%）。已改为 `knockin_parti×(CDI−PDI) + call_parti×CDO`，气囊 35% 偏差从 3.0% 降至 0.03%。
3. **障碍 MC 语义差异（待修）**：
   - 金标：KO 只在 12 个月度观察日判定；rebate = 5% 年化 × ACT365(start→KO 日) × 名义，按 KO 日贴现；
   - 生产引擎：KO 逐日判定（累计路径）；rebate 为到期恒定金额，按到期贴现；
   - 影响：生产障碍 MC 与金标系统值不可直接比较（本报告用独立复现验证金标理解）。建议后续加「观察日列表 + rebate 计划」支持，再补生产侧金标回归。
4. **Delta 口径差异（待确认）**：金标用 spot×0.1% 重抽样；生产用中心差分 1%（共享随机数）。已在文档标注，不影响 PV 验证。
5. **日历版本**：参考日历维护至 2022（其后为推测），金标用例日期均 ≤2022，测试固定使用参考日历；生产日历来自 DB，两者在历史日期上需逐日核对（后续可补差异清单）。

## 4. 结论：能否用于雪球定价？

- **可以用于研究级/条款试定价**：雪球 PV 与金标系统值偏差 ≤0.25%（300k 路径），双时钟/观察日/敲入敲出语义一致；Greeks 为数值差分，可用于风险展示。
- **尚不能称为生产级**，需补齐：
  1. 障碍 MC 的观察日 + rebate 计划（影响障碍类，不影响雪球）；
  2. Delta 口径与金标对齐（bump 0.1% + 公共随机数）；
  3. 真实交易日历 vs 参考日历年差异清单；
  4. 波动率曲面/分红率期限结构（当前为平坦 r/q/σ 假设，与金标一致但非市场曲面）。
- 页面需标注「研究级定价 · 金标对账通过 8/8」，并展示偏差来源说明。
